# 街头篮球抽奖模拟器

街头篮球（端游）各活动的**抽奖概率模拟器**。纯静态单页，无构建、无后端，打开 `index.html` 即用。

## 已实现的活动

| 活动 | 玩法 |
|---|---|
| **闪耀DJ莱克丝** / **华丽DJ杰德** | 单抽 / 10抽 / 50抽 三档概率池，880 点券/次；两者池子相同（仅传说档两件不同），统计各自独立 |
| **徽记卡** | 开卡包 + 合成（单次 / 十连 / 百连 / 一键合成），卡片按「逐张」入库，可查看每张卡的效果 |
| **能力随机卡** | 200 点券/次；「连续购买」会一直抽到目标组合出现为止，次数与花费累计统计 |
| **周宝箱** | 免费开箱：1 个「品质确保」奖励 + N 个随机奖励 |

其他：

- 顶部钱包栏：**点券**（模拟充值，1 元 = 100 点券）、**积分**（用点券购买，不能充值）
- 主题：浅色 / 深色 / 跟随系统，右上角按钮切换
- 所有数据（余额、累计统计、徽记卡库、主题偏好）存在浏览器 localStorage，刷新不丢

## 部署

纯静态站点，**无需构建、无需后端**。所有资源都是相对路径，放在子目录也能跑。

### 在线访问（GitHub Pages）

<https://justhy.github.io/FreeStyleGachaSimulator/>

推送到 `main` 会自动部署（`.github/workflows/deploy-pages.yml`：先跑 `node test.js` 自检，通过后只发布 `index.html` + `img/` + `favicon.ico`）；也可在仓库 Actions 页面手动触发。

### 本地打开

直接双击 `index.html`（或拖进浏览器）即可，无需起服务器。

### 静态服务器 / 托管

把这三项**一起**上传到任意静态目录即可（GitHub Pages、Vercel、Netlify、Nginx、对象存储/CDN 都行）：

```
index.html      # 页面（含全部界面、样式与逻辑）
img/            # 道具图标（27 个 SVG）
favicon.ico     # 网页图标
```

本地起个服务器预览：

```bash
python -m http.server 8000     # 访问 http://localhost:8000
```

> `img/` 与 `favicon.ico` 必须和 `index.html` 保持相对位置，否则图标缺失（缺图会自动回退成 emoji，不会报错）。

## 目录结构

| 文件 | 说明 |
|---|---|
| `index.html` | 页面本体：界面 + 样式 + 全部逻辑（单文件，含内嵌概率表） |
| `img/` | 道具图标（统一风格 SVG） |
| `favicon.ico` | 网页图标 |
| `prizes.js` | 概率表数据源（Node 侧） |
| `lucky.js` | 抽奖内核：加权随机 + 统计（Node 侧） |
| `test.js` | 自检脚本（见下） |

> `prizes.js` / `lucky.js` / `test.js` 只在**开发与校验**时用（Node 运行），部署不需要带上。页面用的是内嵌概率表，改数据时需与 `prizes.js` 保持一致。

## 自检

```bash
node test.js
```

校验概率表合法性、加权随机的卡方分布、页面完整性，以及各活动的数据（徽记卡概率合计、周宝箱掉落表、图标映射等），共 31 项。
